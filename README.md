# 🐍 Exercícios de Python

Este repositório reúne os exercícios desenvolvidos durante meus estudos de programação em Python, iniciados em 2025 e retomados em 2026, utilizando principalmente os conteúdos do **Curso de Python do professor Gustavo Guanabara (Curso em Vídeo)**.

## 📁 Organização do repositório

Os exercícios estão divididos em duas pastas:

- **exercicios_python_2025:** meus primeiros contatos com a linguagem Python e com os conceitos fundamentais de programação.
- **exercicios_python_2026:** retomada dos exercícios realizados anteriormente, revisão dos conhecimentos adquiridos e continuidade do curso, avançando para novos conteúdos.

## 📚 Conteúdos estudados

Ao longo dos exercícios, são abordados conceitos como:

- Variáveis e tipos de dados
- Operadores aritméticos e lógicos
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Strings e manipulação de textos
- Listas, tuplas e dicionários
- Funções e modularização

## 🎯 Objetivo

O objetivo deste repositório é registrar minha trajetória de aprendizado em Python, acompanhar minha evolução na resolução de problemas e desenvolver minhas habilidades de lógica de programação.

Os códigos foram mantidos como registros dos diferentes momentos de estudo, permitindo observar minha evolução ao longo do tempo.
