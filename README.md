# 🐍 Exercícios de Python

Este repositório reúne os exercícios desenvolvidos durante meus estudos de programação em Python, iniciados em 2025 e retomados em 2026, utilizando principalmente os conteúdos do **Curso de Python do professor Gustavo Guanabara (Curso em Vídeo)**.

## 📁 Organização do repositório

Os exercícios estão divididos em duas pastas:

- **exercicios_python_2025:** reúne os códigos originais dos meus primeiros contatos com Python e com os fundamentos da programação, preservados como registros do início do meu aprendizado.
- **exercicios_python_2026:** reúne a retomada dos exercícios, com revisão, organização dos arquivos, adição de comentários explicativos e continuidade dos estudos.

A organização permite acompanhar minha evolução, comparar diferentes momentos de aprendizado e consultar os conceitos praticados em cada exercício.

## 📚 Conteúdos estudados

Ao longo dos estudos, são abordados conceitos como:

- Variáveis, tipos de dados e entrada e saída de informações
- Operadores aritméticos, relacionais e lógicos
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Strings e manipulação de textos
- Listas, tuplas e dicionários
- Funções e modularização
- Importação e utilização de módulos e bibliotecas
